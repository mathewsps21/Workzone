# WorkZone

Código da WorkZone da PS21 (ps21.com.br/workzone).

- `hostgator-index.html` — arquivo único que fica no HostGator em `public_html/workzone/index.html`. Ele busca a versão mais recente deste repositório.
- `loader.js` — login com Google e ponte com o Supabase.
- `app.html` — a WorkZone (Aprovação + Planner).
- `config.json` — endereço e chave pública do Supabase.

Dados, imagens e arquivos ficam no Supabase, protegidos por login. Nada de conteúdo de clientes fica neste repositório.
